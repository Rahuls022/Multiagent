# Web Application Testing

## Overview
Test web applications across functional modules: verify navigation routes, form inputs, validation rules, button actions, data rendering, search filters, and API response contracts.

**Announce at start:** "I'm using the webapp-testing skill to validate interactive user workflows, forms, and functional contracts."

## Core Principles
1. **Interactive Element Validation**: Ensure every button, input, dropdown, and tab triggers expected state changes or DOM updates.
2. **Form Validation Checks**: Verify required fields, email formatting, numeric limits, and error message rendering on invalid input.
3. **Data Grid & Search Verification**: Confirm that search queries and filter options correctly filter displayed rows or cards without exceptions.
4. **Local Persistence Verification**: Ensure changes (like adding items to cart or registering records) persist across page interactions.
5. **Contract Verification**: Verify that frontend API calls match backend route signatures and schemas.
